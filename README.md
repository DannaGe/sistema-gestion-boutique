# Sistema de gestión para la boutique Tique&Mael Fashion

`Proyecto en equipo` · Ingeniería de Software

Documentación completa del análisis y diseño de un sistema de gestión para una
boutique de ropa de mujer, con venta en tienda y en línea.
Instituto Tecnológico de Jiquilpan – Ingeniería en Sistemas Computacionales
(Fundamentos de Ingeniería de Software, diciembre de 2024)

## Problema
La boutique enfrentaba falta de un sistema que organizara sus operaciones,
lo que generaba insatisfacción en las clientas y pérdidas.

## Qué se desarrolló
- Levantamiento de requisitos mediante entrevista con el representante del negocio
- Requisitos funcionales y no funcionales
- Diagrama de casos de uso
- Modelos del sistema
- Planificación del proyecto en Microsoft Project

## Contenido
- **Proyecto final (equipo):** documentación completa de un sistema para una
  boutique: objetivos, alcance, requisitos, modelos y planificación.
- **Casos de uso:** cajero automático, sistema hospitalario y boutique.
- **Requisitos:** funcionales y no funcionales, formato IEEE 830.
- **Diseño UML:** diagrama de clases y modelo de dominio.
